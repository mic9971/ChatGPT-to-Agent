# Work Breakdown / Agent Task Sizing

Prefer one agent task per UC. A large UC may be split only into clearly named sub-slices such as `Core`, `Infrastructure`, `Adapter`, `Tests`, while preserving one shared acceptance checklist.

Recommended task output:

```text
TARGET_UC: UC-...
SCOPE: ...
NON_GOALS: ...
FILES_EXPECTED: ...
BR_REFERENCES: ...
TESTS_REQUIRED: ...
ACCEPTANCE: ...
```

Security-critical UCs (`WS-03/04/05`, `GIT-02`, `EXE-04`, `AUTH-*`, `TUN-*`) should not be bundled together in one agent task.
